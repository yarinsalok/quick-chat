# שיחה מהירה

אפליקציית ווב לטלפון: מקלידים או מדביקים מספר טלפון, ונפתח צ׳אט בוואטסאפ בלי לשמור איש קשר.

## מה יש בה
- קבלת מספר בכל צורה (`050-123-4567`, `+972 50 123 4567`, `00972...`) והמרה לפורמט בינלאומי
- בדיקת תקינות למספרים ישראליים, והתראה על מספר שנראה כמו קו נייח
- הדבקה שמוצאת את המספר גם בתוך טקסט
- הודעה פותחת אופציונלית, עם תרגום אוטומטי: כותבים בעברית ושולחים באנגלית, ערבית, רוסית ועוד (אפשר לערוך את התרגום לפני השליחה)
- רשימת מספרים אחרונים, שנשמרת רק במכשיר
- התקנה כאפליקציה (PWA) ופתיחה גם בלי אינטרנט
- באנדרואיד: אפשר לשתף טקסט עם מספר מכל אפליקציה ישירות אליה

## קבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה: עיצוב ולוגיקה |
| `manifest.webmanifest` | שם, אייקונים ויעד שיתוף להתקנה |
| `sw.js` | מטמון לפתיחה בלי אינטרנט |
| `icon-*.png`, `apple-touch-icon.png` | אייקונים |
